# Third-party source and assets

- **a3d v0.9.3**, commit `9fe271dbadbce239829fd1f9f4d9e6a1ed352c5f`, Eric Nam, Apache 2.0. Source: <https://github.com/0015/a3d>. License accompanies `components/a3d` and `tools/vendor_a3d`. Scout changes add local pose access/reset, a pre-skinning pose callback, mutable non-skinned positions for facial morphs, a per-draw lighting cache, and correct rigid-mesh normal transforms on the projected draw path. The cache has a compile-time baseline switch and pixel-equivalence test. Native rendering also adds a visible-row range (same projection) and replaces per-scanline libm min/max calls with inline comparisons, checked against the original path at native resolution. Further Scout changes dynamically schedule tile work, parallelize binning, isolate the active untextured shader in IRAM, reuse immutable RGB565 material ramps, and apply exact row fades during rasterization. Serial and two-worker host renders are pixel-equivalent across samples spanning all 14 clips. Additional timing counters separate raster work from display submission.
- **RobotExpressive**, Tomás Laulhé / Quaternius, CC0, modified by Don McCurdy. Original model and source record: `assets/source/`. Download: <https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf/RobotExpressive/RobotExpressive.glb>. Scout welds/reduces meshes, adjusts materials, and preserves 14 body clips plus three facial morph targets.
- **IBM Plex Mono Medium**, IBM, SIL Open Font License. Font and license: `assets/fonts/`.
- **Outfit**, Outfit contributors, SIL Open Font License, used for the native UI typography. Variable font and license: `assets/fonts/`. Source: <https://github.com/google/fonts/tree/main/ofl/outfit>.
- **ESP-IDF 5.5.5** and **esp_codec_dev 1.3.6**, Espressif, retain upstream licenses. IDF is external; the component manager resolves the pinned codec dependency.
- **TinyUSB 0.17.0~2**, Espressif component distribution of the MIT-licensed TinyUSB project, provides composite CDC and USB Audio Class microphone support. Pinned in `main/idf_component.yml` and `dependencies.lock`; notices remain in `managed_components/espressif__tinyusb`. **Apache NimBLE**, distributed with ESP-IDF under Apache 2.0, provides the BLE remote service.
- **Ditto Remote app icon**, generated locally with the image generation tool for this private prototype. Source, prompt and packaging notes: `host/mac-remote/Assets/GENERATION.md`. The separate AppKit menu-bar silhouette is code-native artwork. Pokémon/Ditto is a third-party character; the generated icon does not grant rights to the underlying third-party character.
- **esp_lcd_sh8601**, Espressif panel driver, copied from the validated diagnostic project. Notices remain in `components/esp_lcd_sh8601`. The SH8601-compatible transport uses the CO5300 initialization sequence and verified pin mapping for this board.

The panel driver also propagates pixel-transfer errors that the upstream draw function discarded. Scout's compositor follows the paired-coordinate update rule in Waveshare's board-support rounder callback.

The previous engineering avatar was the user's recovered **Gundam Labubu** printing model: embedded designer **Chocobo**, title **高达拉布布labubu.元祖拉布布.无需ams**, license **Standard Digital File License**. Source SHA-256: `92780bbd32c2624c2da2ff0da5043203d8bf73ba1b9f92e49ac1066677768821`. It was read and copied from `book` without remote modification. The local conversion assembles the parts, adds a rigid animation rig, repairs only temporary device copies, reduces geometry and preserves source normals. This is a private local prototype, not a public redistribution license. See `AVATAR-PIPELINE.md`.

The current software rasterizer also uses bounded fixed-point depth stepping for opaque untextured Gouraud spans. A float-reference comparison on an earlier avatar found two differing pixels across 23,051,840 pixels / 112 frames, at intersecting surfaces. Tile scheduling, shading and delayed-transfer checks are retained.

The current avatar is a locally generated **Pokémon Ditto** fan prototype (`tools/prepare_ditto.py`). Its geometry is procedural; it embeds no downloaded Ditto mesh or texture. The artwork used for visual reference is from Pokémon’s official Brilliant Diamond/Shining Pearl site. The recovered Labubu remains archived and is no longer embedded in the current firmware.

The Ditto renderer adds keyed normal-cache entries, fixed screen-space RGB565 dithering, and smooth pre-quantization row attenuation. Current per-asset test evidence is in `test-results/ditto-integration/`; the earlier two-pixel depth figure above belongs to a prior character.

Firmware 0.8.3 extends the a3d software backend with inverse-transpose glossy normals, quadratic normal/light interpolation and a shared precomputed light/fade/dither palette. Legacy paths retain their reference checks. The generated Ditto mesh now checks midpoint-normal error at refined edges to remove the lower-left surface streak. Native glossy interaction frames are identical with one and two workers; the alternate tile-height coverage differences are recorded separately in the current evidence. Board presentation now uses completed frame buffers and CO5300 TE scan synchronization.

## Public source snapshot

The original licensed Labubu/Gundam printing file, derived printing geometry, downloaded Pokémon reference artwork, raw microphone recordings, device dumps and private machine logs are excluded. `tools/prepare_labubu.py` retains the conversion implementation, which requires separately supplied input. The procedural Ditto geometry, animation implementation and generated app artwork are included as an unofficial fan prototype. No project-wide license has been chosen for original project code; all upstream license notices remain applicable.
